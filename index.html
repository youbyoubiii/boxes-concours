Importer la base

Chargez votre CSV pour préparer les groupes

Colonnes utilisées : nom du cheval, sexe, club engageur et surtout club. Les « infos supplémentaires » sont ignorées. Un club renseigné rassemble les chevaux ; sans club, le numéro de réservation sert au regroupement.

Étape 1 · Préparation

Préparer les groupes

Le champ « club » définit le groupe lorsqu’il est renseigné. Sans club, les chevaux sont réunis par réservation ; le cavalier sert de dernier recours. Les noms des chevaux restent visibles.

Règles de voisinage

Choisissez si une paire de chevaux est bloquée, signalée ou autorisée. Les règles s’appliquent côte à côte ; cochez la case pour inclure aussi les boxes exactement en face.

Pour réunir des chevaux, attribuez-leur la même valeur « club ».

Touchez un cheval, puis un box. Le placement automatique rassemble les chevaux par club et évite les conflits.

Étape 2 · Affectation

Plan des boxes

Les couleurs identifient les groupes. Les bandes montrent les paires dos à dos et le passage partagé entre les allées 2 et 3 ; les cases face à face sont alignées.

Placer progressivement par groupe

Pour chaque groupe, choisissez la disposition (selon la place, en ligne ou face à face), puis « Extérieur » ou « Allée intérieure ». Le placement échoue avec un message si cette combinaison n’est plus possible sans conflit bloquant ; les autres groupes déjà placés restent en place. « Placer les groupes restants et compléter » garde ces placements, pose les groupes restants, puis les chevaux isolés sans couper un groupe ni ajouter de conflit bloquant.
